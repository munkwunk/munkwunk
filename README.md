# Hi, I'm Jacob Wood

I'm a blind accessibility professional, an NVDA Certified Expert, and a daily screen reader user. I help teams find and fix the accessibility barriers that automated tools miss, and I use AI to build accessible tools faster.

## What I do

- **Accessibility testing:** I've completed 100+ manual WCAG 2.2 audits of websites, web apps, LMS platforms, e-learning, and documents, testing with NVDA, Narrator, TalkBack, and keyboard only.
- **AI-assisted building:** I build platforms like [Superable Learning](https://www.superablelearning.com), an accessibility-first authoring platform for learning designers. I direct AI coding tools with precise, standards-based instructions and test every change with NVDA.
- **Teaching and community:** I co-host [Beyond Alt Text](https://beyondalttextpod.com), a podcast for people who are their organization's only accessibility champion, and I write weekly about accessibility, learning, and leadership at [Growth for ALL](https://allforgrowth.substack.com).

## Why my repositories look quiet

Most of my work lives in private repositories for my own platform and for client projects. My contribution graph shows that activity, but the code itself stays private. I'm always happy to walk through what I've built.
